# Иконки символов таблицы

Иконки по событиям из раздела 7.2 ТЗ. bolt, barrel, bulldozer и misdeal — из дизайна «Тысяча — дизайн в стиле Гвинта» (48×48, читаются от 20 px), остальные пока заглушки. Чтобы заменить иконку, подмените файл с тем же именем: код не трогается. Цвет задаётся в самом SVG (штрафы красным, бочка жёлтым, победа золотым). Подписи рядом с иконкой (ставка, номер попытки, −120) выводит приложение.

| Файл                | Символ | Событие                                                             |
| ------------------- | ------ | ------------------------------------------------------------------- |
| bid-made.svg        | ▲      | Заказ сыгран                                                        |
| bid-failed.svg      | ▼      | Заказ не сыгран                                                     |
| rospis.svg          | Р      | Роспись                                                             |
| dark.svg            | ◐      | Тёмная                                                              |
| bolt.svg            | •      | Болт (третий болт — с подписью −120)                                |
| prikup.svg          | П      | Сидит на прикупе (вчетвером)                                        |
| barrel.svg          | ▣      | На бочке (с номером кона на бочке)                                  |
| barrel-fall.svg     | ↓      | Падение с бочки или сбит с бочки                                    |
| bulldozer.svg       | ⌀      | Бульдозер                                                           |
| redeal.svg          | ↻      | Пересдача (9, В, 3×9; третья подряд — −120)                         |
| nine-bottom.svg     | ✂      | Девятка или валет внизу при сдвиге (9, В; третий раз подряд — −120) |
| misdeal.svg         | ✕      | Неправильная раздача                                                |
| golden-thousand.svg | ★      | Золотая тысяча                                                      |
| winner.svg          | ♔      | Победитель партии                                                   |
