# Решения по спорным местам правил

Дополняет разделы 2–3 [ТЗ](../tz-web-resource-1000.md). Реализуется в `packages/core`.

| #   | Ситуация                                                   | Решение                                                                                                                                                                                                                                                                                                         |
| --- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | Роспись вдвоём: половина ставки даёт x,5 (105 / 2 = 52,5)  | Округление вверх: 52,5 → 55. Общее правило округления до 5: остаток 0–2 вниз, 2,5 и больше вверх                                                                                                                                                                                                                |
| R2  | Что считается болтом                                       | Игрок не взял ни одной взятки (сырые очки взяток 0). 0 после округления (например, 2 → 0) болтом не считается. Марьяж без взятки объявить нельзя (2.2)                                                                                                                                                          |
| R3  | Бульдозер после штрафа за событие раздачи                  | Бульдозер проверяется после любого изменения счёта, в том числе после −120 за сдвиг, пересдачу или неправильную раздачу (675 → 555 → 0)                                                                                                                                                                         |
| R4  | Бочка занята, в одном коне садятся несколько новых игроков | −120 получают все: и прежний игрок на бочке, и каждый из севших                                                                                                                                                                                                                                                 |
| R5  | Расходует ли попытку на бочке кон без розыгрыша            | Пересдача тем же раздающим попытку не расходует. Если право раздачи перешло к следующему игроку (третья пересдача, девятка внизу 3 раза, неправильная раздача), попытка расходуется. Исключение то же, что для обычного кона: вчетвером, если игрок на бочке был раздающим (на прикупе), попытка не расходуется |
| R6  | Вчетвером, марьяж в прикупе у раздающего                   | При отмеченном марьяже раздающий вводит стоимость третьей карты прикупа, приложение само прибавляет марьяж                                                                                                                                                                                                      |
| R7  | Пример 7.1: тёмная со ставкой 100 противоречит 2.5         | Ставка в тёмную не меньше 120, как в 2.5. Пример 7.1 в ТЗ ошибочен (третий кон), ядро помечает такой кон ошибкой `darkBidTooLow`                                                                                                                                                                                |
