# Тысяча — веб-таблица счёта

Веб-приложение вместо бумажной таблицы при игре в «Тысячу» живыми картами. Считает очки по нашим правилам, хранит историю партий и статистику, показывает общую таблицу на телевизоре в реальном времени. Без регистрации: игрок выбирает своё имя в комнате, устройство его запоминает.

- Техническое задание: [tz-web-resource-1000.md](tz-web-resource-1000.md)
- Решения по спорным правилам (R1–R8): [docs/RULES-DECISIONS.md](docs/RULES-DECISIONS.md)
- План, статус и отступления от ТЗ: [docs/PLAN.md](docs/PLAN.md)
- Деплой на VPS: [docs/DEPLOY.md](docs/DEPLOY.md)

## Возможности

- Комнаты по ссылке, пул игроков, партии на 2–4 игрока, продолжение в любой день.
- Ввод кона с телефонов по этапам: раздача (пересдачи, девятка или валет внизу, тёмная), итог торгов, очки и марьяжи. Ведущий проверяет сумму 120 и подтверждает кон.
- Подсчёт по правилам: роспись, тёмная, прикуп вчетвером, болты, бочка, бульдозер, золотая тысяча.
- Правка любого прошлого кона с пересчётом всей партии и журналом правок.
- Таблица на ТВ (1920×1080) с символами и легендой; символы — SVG-файлы, подменяются без правки кода.
- Статистика по партии, комнате и игроку, личные встречи, график хода партии.
- Установка на телефон (PWA), экспорт партии в CSV и JSON, тёмная тема.

## Устройство

```
packages/core   — правила и подсчёт (replay партии из списка конов), статистика; без зависимостей
apps/server     — Fastify + Socket.IO + SQLite (Drizzle); источник истины
apps/web        — React + Vite; телефон, режим ведущего, ТВ
deploy/         — systemd, pm2, nginx
docs/           — план, решения по правилам, деплой
```

Состояние партии не хранится: оно всегда пересчитывается из конов и событий раздачи функцией `replay` в `packages/core`.

## Команды

```bash
npm install
npm run dev         # сервер :3000 и Vite :5173 (прокси /api и /socket.io)
npm run build       # сборка сервера и фронтенда
npm start           # прод-сервер: API и собранный фронтенд на :3000
npm run typecheck
npm run lint
npm run format
```

Требуется Node.js 22+ (разработка велась на 24).
